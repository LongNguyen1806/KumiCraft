# @kumicraft/cli

The `kumicraft` command. Picks a free port, starts the Local Backend on `127.0.0.1`, creates the session token and opens the Studio in the browser.

Specification: SPEC-01.1 ADR-BE-03, ADR-BE-25, SPEC-05 section 5.

| Command             | Purpose                                              |
| ------------------- | ---------------------------------------------------- |
| `pnpm build` (root) | Build the publishable package (from SPEC-07 WP-0.03) |
