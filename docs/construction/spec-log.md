# Sổ ghi lệch và thiếu so với Spec

Spec chưa hoàn thiện nên thi công không bị chặn bởi Spec. Mỗi khi code làm khác Spec hoặc gặp chỗ Spec chưa nói, ghi một dòng ở đây. Khi cập nhật Spec, chuyển trạng thái dòng thành `Đã đưa vào Spec <phiên bản>`.

Loại: **Lệch** (code khác Spec), **Thiếu** (Spec chưa nói), **Làm lại** (việc đã báo xong nhưng chưa đạt thật), **Hoãn** (dời sang WP khác).
