# Báo cáo kiểm chứng VG-07 — Server local và Hiệu năng

- **Bài kiểm chứng:** VG-07 (SPEC-01.1 mục 12, SPEC-07 mục 5.1)
- **Kiểm chứng cho:** ADR-BE-03 (Chạy local, cổng động), ADR-BE-06 (Fastify 5)
- **Ngân sách liên quan:** PB-02 (Batch operations ≤ 20 ms), PB-10 (Khởi động CLI/server ≤ 2 s)
- **Gói công việc:** WP-0.08 (Spike Backend)
- **Ngày thực hiện:** 2026-10-11
- **Môi trường đo đạc:** Windows 11 Pro, Node 22.19.0, Fastify 5.12.5
- **Kết luận:** **ĐẠT (PASSED)**

---

## 1. Mục tiêu và Tiêu chí đạt

### 1.1. Mục tiêu

Kiểm chứng khả năng bảo vệ mạng loopback và năng lực đáp ứng tải của Fastify 5 khi chạy Local Backend:

1. Đảm bảo server chỉ lắng nghe trên `127.0.0.1` và loại bỏ triệt để các rủi ro kết nối từ mạng ngoài, DNS rebinding hoặc CSRF/Origin giả mạo (SPEC-05).
2. Đảm bảo throughput xử lý batch operations đạt tối thiểu 1.000 ops/giây theo ngân sách PB-02.
3. Đảm bảo thời gian khởi động server đáp ứng ngân sách PB-10 (≤ 2.000 ms).

### 1.2. Tiêu chí đạt theo SPEC-01.1 mục 12

- Server chỉ nhận kết nối từ `127.0.0.1`.
- Request thiếu token hoặc sai Origin bị từ chối 100% (mã lỗi E014).
- 1.000 batch operation/giây qua REST, độ trễ P95 PB-02 đạt (≤ 20 ms).
- Thời gian khởi động đạt ngân sách PB-10 (≤ 2.000 ms).

## 2. Kết quả kiểm chứng chi tiết

Kịch bản kiểm thử độc lập được hiện thực tại [scripts/vg/vg-07.mjs](../../../scripts/vg/vg-07.mjs). Kết quả thực thi thực tế:

### 2.1. Khởi động và Gắn kết Interface (PB-10)

| Chỉ số kiểm tra         | Tiêu chuẩn đặc tả         | Kết quả thực tế                            | Trạng thái |
| ----------------------- | ------------------------- | ------------------------------------------ | ---------- |
| **Interface Binding**   | Chỉ lắng nghe `127.0.0.1` | `http://127.0.0.1:<port>` (Loopback only)  | **ĐẠT**    |
| **Thời gian khởi động** | PB-10: ≤ 2.000 ms         | **97.29 ms** (nhanh hơn ngân sách ~20 lần) | **ĐẠT**    |

### 2.2. Lớp lọc bảo mật mạng (SPEC-05 S-01 đến S-12)

| Kịch bản kiểm tra                | Tiêu chí bảo mật                | Phản hồi thực tế từ server            | Trạng thái |
| -------------------------------- | ------------------------------- | ------------------------------------- | ---------- |
| **Thiếu Authorization**          | Chặn truy cập API               | HTTP 401 (`E014`)                     | **ĐẠT**    |
| **Sai Session Token**            | Chặn token không khớp chữ ký    | HTTP 401 (`E014`)                     | **ĐẠT**    |
| **Origin độc hại**               | Chặn web bên ngoài gọi API      | HTTP 401 (`E014`)                     | **ĐẠT**    |
| **Host độc hại (DNS Rebinding)** | Chặn request sai Host header    | HTTP 421 Misdirected Request (`E014`) | **ĐẠT**    |
| **Request hợp lệ**               | Cho phép Studio nội bộ truy cập | HTTP 200 OK kèm SessionInfo           | **ĐẠT**    |

### 2.3. Tải REST và Độ trễ Batch Operations (PB-02)

Thực hiện gửi tải 2.000 request batch operations liên tiếp (mỗi request chứa mảng 4 thao tác chèn/cập nhật node) qua kết nối HTTP loopback keep-alive với độ đồng thời 20 client.

| Chỉ số đo            | Ngân sách kỹ thuật | Kết quả đo thực tế | Đánh giá                    |
| -------------------- | ------------------ | ------------------ | --------------------------- |
| **Throughput (Tải)** | ≥ 1.000 ops/giây   | **3.609 ops/giây** | Vượt mục tiêu 3,6 lần       |
| **Độ trễ P50**       | —                  | **5.15 ms**        | Rất nhanh                   |
| **Độ trễ P90**       | —                  | **7.56 ms**        | Ổn định                     |
| **Độ trễ P95**       | PB-02: ≤ 20.00 ms  | **8.46 ms**        | Đạt an toàn trong ngân sách |
| **Độ trễ Max**       | —                  | **24.53 ms**       | Không có hiện tượng nghẽn   |

## 3. Kết luận nghiệm thu gói WP-0.08

1. Bài kiểm chứng **VG-07 ĐẠT** toàn bộ tiêu chí.
2. Quyết định kiến trúc **ADR-BE-06 chính thức chuyển sang trạng thái `Accepted`**.
3. Cả hai bài spike kỹ thuật của **WP-0.08** (**VG-01** về an toàn I/O Windows và **VG-07** về mạng và hiệu năng Fastify) đều đã đạt kết quả xuất sắc.
4. Gói công việc **WP-0.08 chính thức hoàn tất (Xong)**.
