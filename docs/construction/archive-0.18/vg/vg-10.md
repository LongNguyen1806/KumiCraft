# Báo cáo kiểm chứng VG-10 — Tailwind runtime trong iframe

- **Bài kiểm chứng:** VG-10 (SPEC-01.2 mục 13, SPEC-07 mục 5.1)
- **Kiểm chứng cho:** ADR-FE-05 (Style trong Canvas: `@tailwindcss/browser` v4 đóng gói offline)
- **Gói công việc:** WP-0.09 (Spike Studio UI)
- **Ngày thực hiện:** 2026-10-11
- **Môi trường đo đạc:** Windows 11 Pro, Chromium headless (Playwright), `@tailwindcss/browser@4.3.3` (offline)
- **Kết luận:** **ĐẠT (PASSED)**

---

## 1. Mục tiêu và Tiêu chí đạt

### 1.1. Mục tiêu

Kiểm chứng thư viện `@tailwindcss/browser` v4 khi nhúng vào Canvas iframe của Studio:

1. Đảm bảo hoạt động hoàn toàn offline mà không tạo ra bất kỳ request mạng nào ra ngoài.
2. Hỗ trợ đầy đủ cú pháp giá trị tùy ý (arbitrary values như `p-[13px]`, `bg-[#123456]`).
3. Khả năng ghi đè và mở rộng cấu hình `@theme` (token màu tùy biến, font, spacing).
4. Độ trễ biên dịch class động trên trang Canvas 500 node đạt tiêu chuẩn ≤ 30 ms.

### 1.2. Tiêu chí đạt theo SPEC-01.2 mục 13

- Trang 500 node, thêm class mới: CSS sẵn sàng ≤ 30 ms.
- Giá trị tùy ý (`p-[13px]`, `bg-[#123456]`) hoạt động chính xác.
- Đổi `@theme` cập nhật toàn bộ Canvas.
- Không có request mạng nào phát sinh (hoạt động độc lập trong môi trường offline).

## 3. Kết luận nghiệm thu

Bài kiểm chứng **VG-10 ĐẠT** toàn bộ tiêu chí. Quyết định kiến trúc **ADR-FE-05 được xác nhận an toàn và chuyển sang trạng thái `Accepted`** (phần runtime).
